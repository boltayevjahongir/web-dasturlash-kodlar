# 12-bob: PostgreSQL CRUD

## Mavzular
- PostgreSQL o'rnatish va psql bilan ishlash
- Ma'lumotlar bazasi va jadval yaratish (CREATE DATABASE, CREATE TABLE)
- Ma'lumot turlari (INTEGER, VARCHAR, TEXT, BOOLEAN, DATE, TIMESTAMP)
- INSERT — ma'lumot kiritish
- SELECT — ma'lumot o'qish (WHERE, ORDER BY, LIMIT)
- UPDATE — ma'lumot yangilash
- DELETE — ma'lumot o'chirish
- Primary Key, NOT NULL, UNIQUE, DEFAULT cheklovlar
