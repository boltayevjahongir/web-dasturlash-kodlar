# Yakuniy Loyihalar

Ushbu papka o'quv qo'llanmaning yakuniy qismidagi amaliy loyihalarni o'z ichiga oladi.
Har bir loyiha tegishli freymvork bo'yicha o'tilgan barcha mavzularni qamrab oladi.

## Loyihalar ro'yxati

| # | Loyiha | Freymvork | Tavsif |
|---|--------|-----------|--------|
| 1 | Flask Blog | Flask | Shaxsiy blog platformasi |
| 2 | Django Online Shop | Django | Onlayn do'kon |
| 3 | FastAPI Task Manager | FastAPI | Vazifalar boshqarish API |
| 4 | Talabalar Portali | Django + FastAPI | Talabalar axborot tizimi |

## Har bir loyiha tuzilishi

```
loyiha_nomi/
├── README.md          - Loyiha haqida batafsil
├── requirements.txt   - Paketlar ro'yxati
├── .env.example      - Muhit o'zgaruvchilari namunasi
├── app/              - Asosiy ilova kodi
├── tests/            - Testlar
├── templates/        - HTML shablonlar
├── static/           - Statik fayllar
└── docker-compose.yml - Docker konfiguratsiya
```
