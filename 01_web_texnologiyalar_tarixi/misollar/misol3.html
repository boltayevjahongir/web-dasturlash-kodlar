HTTP so'rov va javob

HTTP So'rov (Request)

Brauzer serverga so'rov yuboradi:

GET /index.html HTTP/1.1
Host: www.example.com
User-Agent: Mozilla/5.0
Accept: text/html
Accept-Language: uz, en

HTTP Javob (Response)

Server brauzerga javob qaytaradi:

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: 1234
Date: Sat, 11 Apr 2026 12:00:00 GMT

<!DOCTYPE html>
<html>...</html>
