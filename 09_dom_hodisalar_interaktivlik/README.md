# 9-bob: DOM, hodisalar, interaktivlik

## Mavzular
- DOM (Document Object Model) tushunchasi
- Element tanlash (getElementById, querySelector, querySelectorAll)
- Element yaratish va o'chirish (createElement, appendChild, remove)
- Element xususiyatlarini o'zgartirish (textContent, innerHTML, style, classList)
- Hodisalar (events): click, input, submit, keydown, mouseover
- addEventListener va event object
- Event delegation
- Form validatsiya
