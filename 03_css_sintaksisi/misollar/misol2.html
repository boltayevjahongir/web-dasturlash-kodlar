CSS Box Model

1. Asosiy box

margin: 20px; border: 5px; padding: 30px; width: 300px;

Bu elementning umumiy kengligi: 300 + 30*2 + 5*2 + 20*2 = 410px

2. Katta margin

margin: 40px; — tashqi bo'shliq katta

3. Katta padding

padding: 40px; — ichki bo'shliq katta

4. box-sizing: border-box

box-sizing: border-box;

Endi umumiy kenglik aynan 300px — padding va border ichiga kiradi.
